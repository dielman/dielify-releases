# Android app (Phase 6)

Native Kotlin app: Jetpack Compose UI, Media3 (ExoPlayer + MediaSession) for
playback, lock-screen and Android Auto controls. It talks to the PC server's custom
API (discovery, search, download requests) and Subsonic API (library, streaming),
over the home network or Tailscale.

Not started. The API contract will be the OpenAPI spec generated by the server in
Phase 3.
